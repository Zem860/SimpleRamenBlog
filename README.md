# 🍜 SimpleRamenBlog – ViteRamen 分支

這是一個使用 React + Vite 建構的拉麵主題部落格練習專案，並透過 FastAPI 模擬後端 API，實作文章列表、詳細內容與基本 CRUD 資料流程，適合作為前後端分離開發的入門實作。

---

## 🚀 技術棧

- 前端：React + Vite + Bootstrap 5
- 後端：FastAPI（Python）
- 模擬 API 串接
- SPA 架構、RESTful 串接與頁面渲染

---

## ✨ 功能特色

- 文章列表顯示與單篇內頁瀏覽
- 使用者點擊後可進入文章詳情
- 模擬 API 串接（從 FastAPI 回傳 JSON 資料）
- 整合 Bootstrap 提供快速版面設計
- 預留 CRUD 操作介面（如新增/刪除文章）

---
